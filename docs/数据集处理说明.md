# SCB-Dataset3 数据集处理说明

本项目默认使用 YOLO 检测格式：

```text
images/train
images/val
labels/train
labels/val
```

YOLO 标签格式：

```text
class_id center_x center_y width height
```

如果原始标签从 1 开始，需要转换为 0 开始：

```bash
python train/convert_labels_1_to_0.py --src 原始数据集路径 --dst 转换后路径
```

转换后的类别：

| 编号 | 类别 |
|---|---|
| 0 | 举手互动 |
| 1 | 阅读/看书 |
| 2 | 低头书写 |
| 3 | 使用手机 |
| 4 | 低头状态 |
| 5 | 趴桌/疑似睡觉 |
