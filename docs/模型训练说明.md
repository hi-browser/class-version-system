# 模型训练说明

## 一、标签检查

```bash
python train/check_yolo_labels.py --labels "D:/datasets/scb/labels"
```

如果类别为 1~6，需要先转换为 0~5。

## 二、训练命令

```bash
yolo detect train model=yolo11n.pt data=D:/datasets/scb_converted/scb_dataset3.yaml epochs=80 imgsz=640 batch=8 device=0
```

或使用脚本：

```bash
python train/train_yolo_scb.py --data D:/datasets/scb_converted/scb_dataset3.yaml --model yolo11n.pt --epochs 80 --imgsz 640 --batch 8 --device 0
```

## 三、权重放置

训练完成后复制：

```text
runs/scb/scb_yolo/weights/best.pt
```

到：

```text
backend/weights/scb_yolo.pt
```
