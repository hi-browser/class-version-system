# 系统运行说明

## 一、推荐环境

- Windows 11
- Python 3.12.x
- PyCharm
- MySQL 8.x
- Node.js 20+
- NVIDIA RTX 4060 Laptop GPU，可用于 YOLO 训练和推理

## 二、后端启动

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
```

修改 `.env` 中数据库连接信息，然后执行：

```bash
cmd /c "mysql -u root -p < F:\Code\Python\classroom-vision-system\database\classroom_vision.sql"
python run.py
```

## 三、前端启动

```bash
cd frontend
npm install
npm run dev
```

## 四、模型权重

训练完成后将权重放入：

```text
backend/weights/scb_yolo.pt
```

并把 `.env` 中：

```text
MOCK_ANALYSIS=false
```

如果还没有训练好模型，可以保持：

```text
MOCK_ANALYSIS=true
```

用于前后端联调。
